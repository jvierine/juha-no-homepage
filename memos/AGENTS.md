# Memo archive

Publish selected, finished scientific memos here. Each memo must be at most two PDF pages, including references and figures. Verify the page count and visually inspect the exact final PDF before publication.

Use sequential three-digit numbers beginning with 001. Keep the number inside the PDF, its filename, and the archive index consistent. Use TL;DR for the opening summary. Use one caption per figure, graphical legend keys, and compact layouts. Keep code provenance out of figures; include repository links in memo text when the user requests them.
